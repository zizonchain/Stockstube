# DECISIONS
- HackerTube zip holds only the 6,454 kept videos and caps mentions at 20/video, so it is not a full HN YouTube census. Used Algolia for HN instead; zip kept in data/raw/hackertube for reference only.
- HN via Algolia search_by_date with queries "youtube.com" and "youtu.be", comments and stories, windows halved until under the 1,000-hit cap.
- Arctic Shift full-text search throttles bursts with a fake "Timeout" error. Collector uses yearly windows, 1 req/s, backs off 15/30/45/60s, splits a window only after that. Newest years first so a cut-off run keeps recent data.
- Reddit comment thread titles are not in the comment record; left null for comments (posts carry titles). Cost of a lookup per thread was not worth it tonight.
- Thumbnail: hq2.jpg (YouTube's 50% still; hq1/hq3 are 25%/75%). Checked it exists on sample ids; site falls back to hqdefault.jpg on error.
- Recommender = distinct (source, author). AutoModerator and [deleted] dropped from counting entirely (simpler than once-per-thread; [deleted] is rare in these API pulls).
- Arctic Shift: switched to 4s pacing, 30s waits on throttle, monthly windows, comments for all subs first, then link posts. Giveups logged per subreddit.
- Entries the in-session review put in category Other (film clips, sketches, a pitch video, a mock interview) are dropped from the site: people link them in passing, not as investing recommendations.
- Related: shared threads + shared recommenders + same speaker, padded to 12 with the top entries of the same category when the graph is sparse.
- Merge rule adds a title check (token-set ratio >= 60 on clean titles): same speakers + show + year alone wrongly merged two All-In episodes.
- Deep cuts: the brief's recommenders / log10(views+10) alone just reproduced Top (log10 compresses views too much). Added a cap: under 250,000 views.
- Reddit retry (v2 collector): Arctic Shift's fast 'Timeout' is a budget throttle (wait for x-ratelimit-reset), its slow 'Timeout' is a heavy query (split the window). Link posts via indexed url-prefix search over full history first, then comment body search per year. Plain per-subreddit listings work but return 100 items per call even with limit=auto; r/investing alone would need ~100k calls, so they were not used. Academic Torrents sits behind a Cloudflare redirect and no torrent client is installed; skipped.
- Stance: flagged 70 of 2,294 mentions on listed entries with negative-word cues, read all 70 by hand. Most criticised a third party or used the video as evidence. A later pass over excerpts for the top 100 found 3 mentions critical of the video itself (Naval "How to Get Rich" x2, SBF DealBook interview); these are marked critical and do not count. Unflagged mentions are treated as recommendations or neutral references.
- Merge tolerance is 25% duration difference when the in-session labels gave two uploads the identical clean title (trimmed re-uploads of the same lecture, such as Peter Lynch 1994); otherwise 10%.
- Reddit v2: after r/SecurityAnalysis, only the www.youtube.com and youtu.be url prefixes are queried (youtube.com and m.youtube.com added 23 of 1,233 posts there), to fit the night.
- Self-promotion (in-session): Reddit link posts from one or two accounts repeatedly posting the same small channel (Hustle Hub, Andrew explains money, a 'price prediction' stock video) are labelled self_promotion and excluded, alongside the automatic username-to-channel and 3+-videos rules.
- Red days tab: a labelled set (data/labels/red_days.txt) of videos that help an investor through a falling market: temperament during declines plus the history of crashes and recoveries. Crash predictions and bubble-calling are excluded. Sorted by the normal score.
- Strict relevance (maintainer request): only videos squarely about investing stay. General economics, business and startup stories, tech, crypto culture, non-market scams, personal finance outside investing, politics and comedy are excluded via data/labels/strict_out.txt (351 of 686 removed). New candidates are labelled under the same rule.
- Public zip no longer includes YouTube API metadata (titles, channels, views, durations, upload dates), following YouTube terms, as HackerTube does. Video ids remain.
- Ranking changed to HackerTube's rule: score = number of distinct calendar months in which a new person first recommended the video (each person counts once) (after bots, self-promotion and critical mentions are removed); distinct people break ties. Replaces the people x communities x years formula.
- Reddit collection moved to GitHub Actions (.github/workflows/collect.yml, every 6 hours, about 5 hours each). The container sleeps when the session is idle, so local collection only ran minutes per hour. Actions commits data/reddit_extract/*.jsonl.gz: only the text around each YouTube link, hashed usernames, ids and dates, never full comments. Raw API responses stay in the Actions cache. Side effect: the 'username matches channel name' self-promotion rule can no longer run on Reddit; the other two rules and label review still apply.
